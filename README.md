# Chat Manager Bot

Telegram-бот для управления каналами и группами: приём заявок, приветствия, модерация, авто-реакции, отложенные посты и сбор всей активности по чатам в темы лог-группы.

Написан на Python ([aiogram 3](https://docs.aiogram.dev/)) + SQLite.

## Возможности

**Каналы:**
- Приём заявок на вступление (ручной или автоматический).
- Приветствие в личку новым подписчикам: настраиваемый текст, задержка, до 4 inline-кнопок.
- Авто-реакции на посты (с задержкой, выбором эмодзи, поддержкой кастомных реакций подписчиков).
- Реакции на старые посты задним числом и массовое снятие реакций.
- Отложенные посты по расписанию.
- Рассылка по подписчикам.

**Группы:**
- Приветствие новых участников прямо в группе (с автоудалением).
- Модерация: удаление ссылок (с белым списком доменов) и фильтр запрещённых слов.
- Создание и удаление тем форума.

**Общее:**
- Статистика по участникам (всего / за сутки / за неделю).
- Список последних вступивших.
- **Сбор всей информации по каждому чату в отдельную тему лог-группы.**

## Каналы и группы: в чём разница

Бот регистрируется по-разному в зависимости от типа чата:

| Тип | Как добавить |
| --- | --- |
| Канал | Добавь бота админом и перешли мне любой пост из канала (либо бот зарегистрируется сам при добавлении). |
| Группа / супергруппа | Просто добавь бота в группу — она появится автоматически. |

После добавления чат появляется в меню `/menu`.

## Темы для логов

Главная возможность: бот может слать **всю информацию по каждому каналу/группе в отдельную тему** одной общей супергруппы-лога. Удобно, когда чатов несколько — у каждого своя тема, и в ней копятся заявки, новые участники и события модерации.

Как это работает:
- Заводишь **одну супергруппу** с включённым режимом тем (Topics) — она общая для всех чатов.
- Для каждого канала/группы привязывается **одна тема**.
- Заявки, новые участники и удалённые модерацией сообщения по этому чату уходят именно в его тему.
- Если тема ещё не настроена — уведомления приходят админу в личку (ничего не теряется).

Автоматизация и надёжность:
- При добавлении нового канала/группы бот **автоматически создаёт тему** под него и привязывает (если лог-группа уже задана).
- Кнопка «Создать темы для всех чатов» заводит темы разом для всех уже добавленных чатов.
- Если тему вручную удалить, бот при следующем событии **пересоздаст** её (самовосстановление). Чтобы тема не возвращалась, отключи логи кнопкой «Логи в тему: ВЫКЛ».

## Настройка (.env)

Создай файл `.env` (по образцу `.env.example`):

```env
BOT_TOKEN=123456789:AAH...        # токен от @BotFather
ADMIN_ID=123456789                # твой Telegram ID
TIMEZONE_OFFSET=3                 # смещение часового пояса (3 = МСК, UTC+3)
```

| Переменная | Описание |
| --- | --- |
| `BOT_TOKEN` | Токен бота. Получить у @BotFather командой `/newbot`. |
| `ADMIN_ID` | Твой Telegram ID. Только этот пользователь может управлять ботом. |
| `TIMEZONE_OFFSET` | Смещение от UTC в часах. По умолчанию `3`. |

## Настройки в @BotFather и права бота

Чтобы всё работало, нужно правильно настроить бота.

### 1. Privacy Mode (для модерации в группах)

Чтобы бот видел сообщения участников (для фильтров) — отключи приватность:

`@BotFather` → `/mybots` → **Bot Settings** → **Group Privacy** → **Turn off**.

### 2. Права в канале

Боту нужны права админа: добавлять участников и публиковать сообщения.

### 3. Права в группе

Боту нужны права админа: удалять сообщения (для модерации) и **управлять темами** (для создания/удаления тем — это обязательно для лог-группы).

> Для приёма заявок в настройках канала/группы включи режим «Заявки на вступление» (Approve new members).

## Запуск на Windows

1. Установи Python с [python.org](https://www.python.org/downloads/), отметь галочку **Add Python to PATH**.
2. Проверь установку (`Win + R` → `cmd`):
   ```
   python --version
   ```
3. Перейди в папку проекта:
   ```
   cd C:\путь\к\проекту
   ```
4. Создай и активируй виртуальное окружение:
   ```
   python -m venv venv
   venv\Scripts\activate
   ```
   > Если PowerShell ругается на запуск скриптов, используй `cmd` или выполни: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
5. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
6. Создай `.env` (см. [Настройка](#настройка-env)). Следи, чтобы не было расширения `.txt`.
7. Запусти:
   ```
   python bot.py
   ```
   Остановить — `Ctrl + C`.

Последующие запуски:
```
venv\Scripts\activate
python bot.py
```
> Пока окно открыто — бот работает. Для работы 24/7 нужен сервер.

## Команды бота

В личке (видны всем, кто открыл бота):

| Команда | Что делает |
| --- | --- |
| `/start`, `/menu` | Открыть меню управления чатами. |
| `/reactall <chat_id> [глубина]` | Поставить реакции на старые посты канала. |

Для админов в группах/супергруппах:

| Команда | Что делает |
| --- | --- |
| `/newtopic <название>` | Создать тему форума. |
| `/topics` | Показать список созданных ботом тем (с их id). |
| `/deltopic <id>` | Удалить тему по id (id смотри в `/topics`). |

## Как пользоваться

### Базовая настройка

1. Запусти бота, открой его в личке, отправь `/start`.
2. Добавь канал (перешли пост) или группу (просто добавь бота). Они появятся в `/menu`.
3. Зайди в нужный чат через меню и настрой приветствия, модерацию, реакции и т.д.

### Настройка тем для логов

1. Создай отдельную **супергруппу** и включи в её настройках режим тем (Topics).
2. Добавь бота в эту группу админом с правом **«Управление темами»**.
3. Открой `/menu` → выбери любой чат → **«🧵 Тема для логов»** → **«Задать лог-группу»** и пришли её ID (вида `-100...`). Лог-группа общая для всех чатов — задаётся один раз.
4. Нажми **«Создать темы для всех чатов»** — бот заведёт тему под каждый чат и привяжет их.
5. Готово. Дальше каждый новый чат получает свою тему автоматически.

Чтобы привязать чат к уже существующей теме вручную — создай её командой `/newtopic` прямо в лог-группе, затем в меню чата нажми «📋 Выбрать тему».

### Удаление темы чата

В меню чата → «🧵 Тема для логов» → «🗑 Удалить тему этого чата». Бот удалит тему в Telegram и отключит логи по этому чату, чтобы она не создалась заново. Включить обратно можно кнопкой «Логи в тему».

## Запуск на сервере 24/7

На VPS удобнее всего через systemd-сервис.

1. Создай файл сервиса:
   ```bash
   sudo nano /etc/systemd/system/mybot.service
   ```
2. Содержимое (поправь пути под себя):
   ```ini
   [Unit]
   Description=Telegram Chat Manager Bot
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/root/mybot
   ExecStart=/root/mybot/venv/bin/python /root/mybot/bot.py
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```
3. Запусти:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable mybot
   sudo systemctl start mybot
   ```

Управление:
```bash
systemctl status mybot      # статус
journalctl -u mybot -f      # логи в реальном времени
systemctl restart mybot     # перезапуск (например после git pull)
systemctl stop mybot        # остановить
```

> `.env` правь прямо на сервере (`nano .env`), в Git его не коммить.

## Частые вопросы

**Бот не видит сообщения в группе.** Отключи Privacy Mode в @BotFather и переустанови бота в группу.

**Тема для чата не создаётся автоматически.** Убедись, что лог-группа задана, это супергруппа с включёнными темами, и у бота есть право «Управление темами».

**Удалённая тема создаётся заново.** Это самовосстановление. Чтобы тема не возвращалась, отключи логи для чата кнопкой «Логи в тему: ВЫКЛ» (или удали тему через кнопку «Удалить тему этого чата» — она отключает логи сама).

**Уведомления приходят в личку, а не в тему.** Значит лог-группа или тема для этого чата ещё не настроены — это нормальное поведение по умолчанию (fallback).

**Время постов отображается неправильно.** Проверь `TIMEZONE_OFFSET` в `.env`.

**Где взять ID лог-группы.** Добавь временно `@getmyid_bot` в группу, либо посмотри id в списке чатов в `/menu`.

**Где хранятся данные.** В файле `bot.db` (SQLite) — чаты, настройки, участники, темы, посты.

## Безопасность

- Не публикуй `.env` — там токен и твой ID.
- Не коммить `bot.db` — там данные пользователей.
- Перед `git push` проверь `git status`, что `.env` и `bot.db` в `.gitignore`.
