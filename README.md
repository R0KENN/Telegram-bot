# 🤖 Chat Manager Bot

Многофункциональный Telegram-бот для управления каналами и группами из одного места: приём заявок, кастомные приветствия с кнопками, модерация групп, рассылки и отложенный постинг.

Написан на Python с использованием [aiogram 3](https://docs.aiogram.dev/), данные хранятся в локальной базе SQLite.

## ✨ Возможности

**Для каналов:**
- Автоматический приём заявок на вступление (включается отдельно для каждого канала).
- Кастомное приветствие в личку: включение/выключение, настройка текста с форматированием, задержка перед отправкой и до 4 кнопок-ссылок.
- Рассылка сообщений всем, кто прошёл через бота.
- Отложенный постинг: запланируй пост с текстом и кнопкой на нужные дату и время.

**Для групп:**
- Приём заявок (для закрытых групп).
- Модерация: удаление ссылок от не-админов с белым списком разрешённых доменов.
- Фильтр запрещённых слов: сообщения с ними удаляются.
- Приветствие новых участников прямо в группе с автоудалением через заданное время и подстановкой имени.

**Общее:**
- Управление любым числом каналов и групп из одного бота, у каждого свои настройки.
- Удобное кнопочное меню — без запоминания команд.
- Статистика: всего участников, прирост за сутки и за неделю, список последних.
- Уведомления администратору о новых заявках и добавлении в группы.
- Все настройки и данные сохраняются между перезапусками.

## 🔀 Каналы и группы: в чём разница

Бот работает и с каналами, и с группами, но функции у них разные, потому что это разные сущности Telegram:

| Функция                      | Канал | Группа |
|------------------------------|:-----:|:------:|
| Приём заявок                 |  ✅   |   ✅   |
| Приветствие в личку + кнопки |  ✅   |   —    |
| Рассылка                     |  ✅   |   —    |
| Отложенные посты             |  ✅   |   —    |
| Модерация (ссылки, слова)    |   —   |   ✅   |
| Приветствие в группе         |   —   |   ✅   |

Меню для каналов и групп различается автоматически — бот сам определяет тип чата.

Создай файл `.env` в корне проекта (можно скопировать из `.env.example`) и заполни:

```env

TIMEZONE_OFFSET=3                 # часовой пояс (3 = Москва, UTC+3)
```

| Переменная        | Описание                                                    |
|-------------------|-------------------------------------------------------------|
| `BOT_TOKEN`       | Токен бота. Получи у @BotFather командой `/newbot`.        |
| `ADMIN_ID`        | Твой числовой ID. Только ты управляешь ботом.             |
| `TIMEZONE_OFFSET` | Смещение от UTC для времени постов. Москва — `3`.         |

## 🛠 Важно: настройки в @BotFather и права бота

Без этих шагов модерация групп работать **не будет**.

### 1. Отключи Privacy Mode (для групп)

По умолчанию бот не видит обычные сообщения в группах и не может их модерировать. Чтобы это исправить:

@BotFather → `/mybots` → выбери бота → **Bot Settings** → **Group Privacy** → **Turn off**.

### 2. Дай боту права админа

**В канале** боту нужны права:
- «Добавлять участников» — для приёма заявок;
- «Публикация сообщений» — для отложенных постов.

**В группе** боту нужны права:
- «Удалять сообщения» — для модерации;
- «Добавлять участников» — для приёма заявок (если группа закрытая).

### 3. Включи заявки на вступление (если нужно)

Для приёма заявок в настройках канала/группы включи тип **«Заявки на вступление»** (Approve new members), чтобы пользователи отправляли заявки, а не вступали сразу.

> ⚠️ **Автоприём заявок по умолчанию выключен** для каждого нового канала и группы. После добавления зайди в меню и включи его вручную, когда будешь готов.

## 💻 Запуск локально на Windows

1. Установи Python с [python.org](https://www.python.org/downloads/), **обязательно поставив галочку «Add Python to PATH»** при установке.
2. Проверь установку в командной строке (`Win + R` → `cmd`):
   ```cmd
   python --version
   ```
3. Скачай проект (через `git clone` или кнопкой **Code → Download ZIP** на GitHub) и перейди в его папку:
   ```cmd
   cd C:\путь\к\папке
   ```
   > 💡 Быстро открыть консоль в папке: набери `cmd` в адресной строке Проводника и нажми Enter.
4. Создай и активируй виртуальное окружение:
   ```cmd
   python -m venv venv
   venv\Scripts\activate
   ```
   > ⚠️ Если PowerShell ругается на политику выполнения скриптов, используй обычный `cmd` или выполни: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
5. Установи зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
6. Создай файл `.env` (см. раздел [Настройка](#-настройка)). При создании в Блокноте выбери «Тип файла: Все файлы» и имя `.env` без `.txt`.
7. Запусти бота:
   ```cmd
   python bot.py
   ```
   Остановить — `Ctrl + C`.

**Повторный запуск** (всё уже установлено):
```cmd
venv\Scripts\activate
python bot.py
```

> ℹ️ На домашнем ПК бот работает только пока открыто окно консоли и компьютер включён. Для работы 24/7 используй сервер.

## 📖 Как пользоваться

Управление происходит в личном чате с ботом и доступно только администратору.

### Добавление чата

- **Канал:** добавь бота админом в канал и перешли боту любой пост оттуда — канал появится в списке. (Также добавится сам после первой заявки.)
- **Группа:** просто добавь бота админом в группу — она появится автоматически, бот пришлёт уведомление.

### Главное меню

Команда `/start` или `/menu` открывает список твоих каналов (📢) и групп (👥). Выбери чат, чтобы настроить его.

### Меню канала

| Кнопка                     | Что делает                                              |
|----------------------------|--------------------------------------------------------|
| 📊 Статистика              | Всего вступивших, прирост за сутки и неделю.           |
| 🕓 Последние               | Список 10 последних вступивших.                        |
| 🟢/🔴 Автоприём            | Включает/выключает автоодобрение заявок.               |
| ⚙️ Приветствие (в личку)   | Настройка приветствия и кнопок (см. ниже).             |
| 📨 Рассылка                | Сообщение всем участникам канала.                      |
| 📝 Посты                   | Отложенный постинг (см. ниже).                         |
| ♻️ Сбросить настройки      | Возврат настроек к умолчанию (участники сохраняются).  |

### Меню группы

| Кнопка                     | Что делает                                              |
|----------------------------|--------------------------------------------------------|
| 📊 Статистика / 🕓 Последние | Как у канала.                                        |
| 🟢/🔴 Автоприём            | Автоодобрение заявок (для закрытых групп).             |
| 🛡 Модерация               | Удаление ссылок и фильтр слов (см. ниже).              |
| 👋 Приветствие в группе    | Приветствие новых участников в чате (см. ниже).        |
| ♻️ Сбросить настройки      | Возврат настроек к умолчанию.                          |

### Кастомное приветствие в личку (каналы)

В разделе «⚙️ Приветствие»:
- **Вкл/выкл** — целиком включить или отключить приветствие.
- **Текст** — пришли новый текст; форматирование (жирный, курсив, ссылки словами) делается прямо в Telegram.
- **Задержка** — через сколько секунд после одобрения отправить приветствие (`0` — сразу).
- **Кнопки** — до 4 кнопок-ссылок; для каждой задаётся текст и URL.
- **Проверить** — показать приветствие так, как его увидит новый участник.

> ℹ️ Бот может написать в личку только тем, кто хоть раз взаимодействовал с ботом. Это ограничение Telegram.

### Модерация группы

В разделе «🛡 Модерация»:
- **Удалять ссылки** — удаляет сообщения со ссылками от не-админов. Админов группы не трогает.
- **Разрешённые домены** — белый список; ссылки на эти домены (и их поддомены) не удаляются. Например: `t.me`, `youtube.com`.
- **Фильтр слов** — удаляет сообщения, содержащие запрещённые слова.
- **Запрещённые слова** — список слов для фильтра.

### Приветствие в группе

В разделе «👋 Приветствие в группе»:
- **Вкл/выкл** — включить или отключить.
- **Текст** — сообщение для новых участников. Подстановка `{name}` заменится на имя вошедшего.
- **Автоудаление** — через сколько секунд удалить приветствие из чата (`0` — не удалять), чтобы не засорять группу.

### Рассылка (каналы)

Нажми «📨 Рассылка», пришли сообщение — оно уйдёт всем участникам канала, доступным для личных сообщений. В конце бот покажет отчёт.

> ⚠️ Не злоупотребляй: частые массовые рассылки могут привести к ограничениям Telegram.

### Отложенный постинг (каналы)

«📝 Посты» → «➕ Новый отложенный пост», три шага:
1. Текст поста (с форматированием).
2. Кнопка `Название | https://ссылка` или «Без кнопки».
3. Дата и время `ДД.ММ.ГГГГ ЧЧ:ММ`, например `25.12.2026 20:00` (по часовому поясу из `.env`).

Все запланированные посты видны в этом разделе — нажми на любой, чтобы отменить.

## 🖥 Запуск на сервере 24/7

Для постоянной работы запусти бота на VPS как systemd-службу.

1. Создай файл службы:
   ```bash
   sudo nano /etc/systemd/system/mybot.service
   ```
2. Вставь (поправь пути):
   ```ini
   [Unit]
   Description=Telegram Chat Manager Bot
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/root/mybot
   ExecStart=/root/mybot/venv/bin/python /root/mybot/bot.py
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```
3. Активируй:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable mybot
   sudo systemctl start mybot
   ```

**Полезные команды:**
```bash
systemctl status mybot      # статус
journalctl -u mybot -f      # логи в реальном времени
systemctl restart mybot     # перезапуск (после git pull)
systemctl stop mybot        # остановка
```

> 💡 Файл `.env` создавай прямо на сервере (`nano .env`), а не заливай через Git.

## ❓ Частые вопросы

**Бот не удаляет сообщения в группе.**
Проверь два условия: отключён ли Privacy Mode в @BotFather и есть ли у бота право «Удалять сообщения» в группе. Также модерация не трогает сообщения админов.

**Группа не появилась в списке.**
Убедись, что бот добавлен в группу как администратор. Если не появилась — напиши боту `/menu` и проверь снова.

**Канал не появляется в списке.**
Добавь бота админом в канал и перешли боту пост оттуда, либо дождись первой заявки.

**Заявки не принимаются автоматически.**
Автоприём по умолчанию выключен. Зайди в меню чата и включи его кнопкой «Автоприём».

**Приветствие не приходит в личку новым участникам канала.**
Telegram запрещает ботам писать первыми тем, кто никогда с ботом не общался. Это ожидаемое поведение.

**Ссылки на разрешённый домен всё равно удаляются.**
Проверь, что домен добавлен в белый список без `http://` и `www` (например, просто `youtube.com`). Поддомены разрешённого домена тоже не удаляются.

**Отложенный пост не опубликовался.**
Проверь право бота публиковать сообщения в канале. При ошибке бот присылает админу уведомление с причиной.

**Время постов сместилось.**
Проверь `TIMEZONE_OFFSET` в `.env`.

**Как сбросить всё начисто.**
Останови бота и удали файл `bot.db` — он пересоздастся при следующем запуске. Вместе с настройками удалятся участники, посты, кнопки, домены и слова.

## 🔒 Безопасность

- Храни токен только в `.env`, никогда не коммить его в репозиторий.
- Не публикуй файл `bot.db` — в нём данные твоей аудитории.
- Перед каждым `git push` проверяй командой `git status`, что `.env` и `bot.db` отсутствуют в списке файлов.
