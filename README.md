# 🤖 Channel Manager Bot

Многофункциональный Telegram-бот для управления несколькими каналами из одного места: автоматический приём заявок на вступление, приветствия новым участникам, рассылки и отложенный постинг с кнопками.

Бот написан на Python с использованием [aiogram 3](https://docs.aiogram.dev/) и хранит все данные в локальной базе SQLite.

## ✨ Возможности

- **Автоматический приём заявок.** Бот сам одобряет заявки на вступление в канал. Автоприём можно включать и выключать для каждого канала отдельно.
- **Управление несколькими каналами.** Один бот обслуживает любое число каналов, у каждого свои индивидуальные настройки.
- **Приветственное сообщение.** Настраиваемый текст с поддержкой форматирования (жирный, курсив, ссылки словами) и кнопкой со ссылкой на правила. Отправляется новому участнику с настраиваемой задержкой.
- **Рассылка.** Отправка сообщения всем, кто прошёл через бота в конкретный канал.
- **Отложенный постинг.** Запланируй пост с текстом и кнопкой на нужные дату и время — бот опубликует его в канал автоматически.
- **Статистика.** Общее число вступивших, прирост за сутки и за неделю, список последних участников.
- **Кнопочное меню.** Всё управление через удобные inline-кнопки, без запоминания команд.
- **Уведомления администратору** о каждой новой заявке.
- **Сохранение между перезапусками.** Все настройки, участники и запланированные посты хранятся в базе и не теряются при перезагрузке бота.

## 📦 Установка

1. Склонируй репозиторий и перейди в папку проекта:

   ```bash
   git clone https://github.com/ТВОЙ_ЛОГИН/ТВОЙ_РЕПОЗИТОРИЙ.git
   cd ТВОЙ_РЕПОЗИТОРИЙ
   ```

2. Создай виртуальное окружение и активируй его:

   ```bash
   python3 -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   ```

3. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## ⚙️ Настройка

1. Создай файл `.env` в корне проекта (можно скопировать из шаблона `.env.example`):

   ```bash
   cp .env.example .env
   ```

2. Открой `.env` и заполни поля:

   ```env
   BOT_TOKEN=123456789:AAH...        # токен от @BotFather
   ADMIN_ID=123456789                # твой Telegram ID
   TIMEZONE_OFFSET=3                 # часовой пояс (3 = Москва, UTC+3)
   ```

   | Переменная        | Описание                                                        |
   |-------------------|-----------------------------------------------------------------|
   | `BOT_TOKEN`       | Токен бота. Получи у @BotFather командой `/newbot`.             |
   | `ADMIN_ID`        | Твой числовой ID. Только этот пользователь управляет ботом.     |
   | `TIMEZONE_OFFSET` | Смещение от UTC для ввода времени постов. Москва — `3`.         |

3. Подготовь каналы:
   - Добавь бота **администратором** в каждый канал.
   - Дай ему права **«Добавлять участников»** (для приёма заявок) и **«Публикация сообщений»** (для отложенных постов).
   - В настройках канала включи тип **«Заявки на вступление»** (Approve new members), чтобы пользователи отправляли заявки, а не вступали сразу.

> ⚠️ **Важно:** никогда не публикуй файл `.env` и базу `bot.db`. Они содержат токен и данные твоей аудитории. Файл `.gitignore` уже настроен так, чтобы исключить их из репозитория.

## 📖 Как пользоваться

Всё управление происходит в личном чате с ботом и доступно только администратору (чей ID указан в `.env`).

### Главное меню

Отправь боту команду `/start` или `/menu`. Откроется список твоих каналов и кнопка **«➕ Добавить канал»**.

### Добавление канала

Есть два способа:

1. **Вручную (быстро):** нажми «➕ Добавить канал», затем перешли боту любое сообщение из нужного канала. Канал сразу появится в списке.
2. **Автоматически:** канал добавится сам, как только в него поступит первая заявка на вступление.

В обоих случаях бот должен быть администратором канала.

### Меню канала

Выбери канал из списка — откроется его панель управления:

| Кнопка                     | Что делает                                                          |
|----------------------------|---------------------------------------------------------------------|
| 📊 **Статистика**          | Всего вступивших, прирост за сутки и за неделю, статус автоприёма.  |
| 🕓 **Последние**           | Список 10 последних вступивших с временем.                          |
| 🟢/🔴 **Автоприём**        | Включает или выключает автоматическое одобрение заявок.             |
| ⚙️ **Приветствие**         | Настройка приветственного сообщения (см. ниже).                     |
| 📨 **Рассылка**            | Отправка сообщения всем участникам этого канала.                    |
| 📝 **Посты**               | Отложенный постинг (см. ниже).                                      |
| ♻️ **Сбросить настройки**  | Возврат настроек канала к значениям по умолчанию (участники остаются). |

### Настройка приветствия

В разделе **«⚙️ Приветствие»** доступно:

- **✏️ Текст** — изменить текст приветствия. Просто пришли новый текст; форматирование (жирный, курсив, ссылки словами) можно сделать прямо в Telegram — бот сохранит разметку.
- **⏱ Задержка** — через сколько секунд после одобрения отправлять приветствие (`0` — сразу).
- **🔗 Ссылка на правила** — URL для кнопки «Правила» под приветствием.
- **👁 Проверить** — показать приветствие так, как его увидит новый участник.

> ℹ️ Бот может написать пользователю в личку только если тот хоть раз взаимодействовал с ботом. Это ограничение Telegram, поэтому иногда приветствие не доставляется — это нормально.

### Рассылка

Нажми **«📨 Рассылка»**, пришли сообщение (можно с форматированием) — оно уйдёт всем участникам этого канала, кто доступен для личных сообщений. В конце бот покажет отчёт: сколько доставлено и сколько нет.

> ⚠️ Не злоупотребляй рассылками: слишком частые или массовые сообщения могут привести к ограничениям со стороны Telegram.

### Отложенный постинг

В разделе **«📝 Посты»** нажми «➕ Новый отложенный пост» и пройди три шага:

1. **Текст поста** — пришли текст (можно с форматированием).
2. **Кнопка** — пришли в формате `Название | https://ссылка` или нажми «Без кнопки».
3. **Дата и время** — в формате `ДД.ММ.ГГГГ ЧЧ:ММ`, например `25.12.2026 20:00` (по часовому поясу из `TIMEZONE_OFFSET`).

Пост попадёт в очередь. В этом же разделе видны все запланированные посты — нажми на любой, чтобы отменить. В назначенное время бот сам опубликует пост в канал и пришлёт тебе подтверждение.

## 🖥 Запуск на сервере 24/7

Чтобы бот работал постоянно, его нужно запустить на сервере (VPS с Linux). После установки и настройки оформи его как системную службу.

1. Создай файл службы:

   ```bash
   sudo nano /etc/systemd/system/mybot.service
   ```

2. Вставь (поправь пути под свои):

   ```ini
   [Unit]
   Description=Telegram Channel Bot
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/root/mybot
   ExecStart=/root/mybot/venv/bin/python /root/mybot/bot.py
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```

3. Активируй службу:

   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable mybot
   sudo systemctl start mybot
   ```

**Полезные команды:**

```bash
systemctl status mybot      # статус
journalctl -u mybot -f      # логи в реальном времени
systemctl restart mybot     # перезапуск (например, после git pull)
systemctl stop mybot        # остановка
```

> 💡 Файл `.env` создавай прямо на сервере вручную (`nano .env`), а не заливай через Git.

## ❓ Частые вопросы

**Канал не появляется в списке.**
Убедись, что бот добавлен администратором в канал. Затем перешли боту сообщение из канала или дождись первой заявки.

**Приветствие не приходит новым участникам.**
Telegram запрещает ботам писать первыми тем, кто никогда с ботом не общался. Это ожидаемое ограничение, не ошибка.

**Отложенный пост не опубликовался.**
Проверь, что у бота есть право публиковать сообщения в канале. При ошибке бот присылает администратору уведомление с описанием причины.

**Время постов сместилось.**
Проверь `TIMEZONE_OFFSET` в `.env`. Значение должно соответствовать твоему часовому поясу (Москва — `3`).

**Бот перестал работать после перезапуска сервера.**
Если оформил его как systemd-службу с `Restart=always` и `enable`, он поднимется сам. Проверь статус через `systemctl status mybot`.

**Как сбросить всё начисто?**
Останови бота и удали файл `bot.db` — он пересоздастся при следующем запуске. Учти, что вместе с настройками удалятся списки участников и запланированные посты.
